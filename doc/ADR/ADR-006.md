
# ADR-006 — Use Flyway for Database Migration

## Status

Accepted

## Context

Database schema evolution must remain:

* versioned
* reproducible
* auditable
* deterministic

Relying on automatic schema generation would:

* reduce migration visibility
* increase deployment risk
* weaken operational discipline

## Decision

Use Flyway for schema migration management.

Migration files will be version-controlled.

Example:

```text
V1__create_accounts.sql
V2__create_ledger_entries.sql
```

## Consequences

### Positive

* deterministic schema evolution
* safer deployments
* production-style workflow
* auditable schema history

### Negative

* manual migration management required
* increased setup discipline
