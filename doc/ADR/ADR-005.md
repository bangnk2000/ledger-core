
# ADR-005 — Use PostgreSQL as Primary Database

## Status

Accepted

## Context

LedgerCore requires:

* strong transactional guarantees
* MVCC support
* row-level locking
* transactional consistency
* mature SQL capabilities
* indexing flexibility
* auditability support

The database must support:

* ACID transactions
* pessimistic locking
* optimistic locking
* transactional integrity
* future partitioning

## Decision

Use PostgreSQL as the primary relational database.

## Consequences

### Positive

* strong transaction support
* mature MVCC implementation
* robust concurrency handling
* excellent tooling ecosystem
* strong SQL capabilities
* production-proven reliability

### Negative

* horizontal write scaling complexity
* operational complexity increases at scale

## Notes

PostgreSQL features expected to be explored:

* MVCC
* isolation levels
* row-level locking
* partitioning
* WAL
* indexing strategies
* replication concepts
