# ADR-001 — Use Modular Monolith as Initial Architecture

## Status

Accepted

## Context

LedgerCore is intended to evolve into a distributed financial transaction platform focused on:

* transaction consistency
* ledger integrity
* auditability
* idempotent processing
* event-driven workflows
* reconciliation
* reliability under concurrency

At the beginning of the project:

* the domain is still evolving
* transaction boundaries are not fully stabilized
* business invariants are still being discovered
* operational complexity should remain manageable

A full microservice architecture at this stage would introduce:

* distributed transaction complexity
* deployment overhead
* network failure handling
* service discovery complexity
* duplicated infrastructure concerns
* reduced development speed
* harder debugging

## Decision

Use a Modular Monolith architecture initially.

The system will:

* run as a single deployable application
* use a single PostgreSQL database initially
* separate domains by module boundaries
* maintain strict dependency direction
* remain event-driven ready

Initial domain modules:

* account
* transfer
* ledger
* transaction
* reconciliation
* shared/common

## Consequences

### Positive

* simpler operational model
* easier debugging
* transactional consistency is easier to maintain
* faster iteration during domain discovery
* easier refactoring of aggregates and boundaries
* reduced infrastructure overhead
* easier onboarding

### Negative

* independent scaling per module is not possible initially
* deployment remains centralized
* module boundaries rely on discipline rather than network isolation

## Future Evolution

The architecture may evolve into distributed services when:

* transaction throughput significantly increases
* operational isolation becomes necessary
* asynchronous workflows become dominant
* read/write scaling diverges significantly
* independent deployment becomes valuable

Potential future extracted services:

* reconciliation-worker
* notification-worker
* analytics-service
* reporting-service
* fraud-detection-service
